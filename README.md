## Как запустить

Переходим в папку sharding

```shell
cd sharding-repl-cache
```

Запускаем приложение и его инфраструктуру:

```shell
docker compose up -d
```

Инициализируем базу и шарды через запуск скрипта (нужно некоторое время подождать, пока наполнится база и синхронизируются реплики)

```shell
./scripts/mongo-init.sh
```

## Как проверить

Запустив команду можно увидеть данные по всем шардам и репликам (количество документов), а так же скорость работы запроса с кешированием и без

```shell
./scripts/mongo-test.sh
```
